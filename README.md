# Transparent PNG — GitHub Pages (CWS)

Welcome (and later privacy) for the store. Layout matches **`subscription-tracker-pages`**.

## Screenshots

Add your own exports to **`images/`** (see **`images/README.txt`**). Do not commit broken placeholders.

## Publish

1. Repo **`transparent-png-pages`** on GitHub.
2. Copy **contents of this folder** to the repo root.
3. **Settings → Pages** → branch **`main`**, folder **`/`**.
4. URL: `https://<user>.github.io/transparent-png-pages/welcome.html`

## Extension

Open the same welcome URL on first install when the Pages URL is live (wire in extension with «делай»).
